# 使用說明

[開啟瑪奇小算盤](https://bbyuu.github.io/CalculMabi/)

## 技能

先選技能，再選一般修練或升段。一般修練設定起始與目標 Rank，加成分為修練次數與修練值；勾選練到 30% 可降低每階目標。各階修練項目全部展開，可調整項目及配方，材料消耗同步更新。

計算涵蓋到達目標 Rank 之前的階級。已有進度時，填入修練值與已計數次數；尚未達標的合計會以紅色標示。材料不完整的配方不視為零耗材。

## 升段

打鐵、衣物製作依 NPC 位置勾選成品，下方集中顯示材料數量及設計圖或樣本。魔法製造、稀原工學每階段選一個固定目標，材料按商店批量顯示組數，前置材料附用途。

## 聚能

選擇武器、起始與目標階段，再設定單階目標累積成功率。各階可獨立勾選藥水或輸入嘗試次數；跨級別可勾選轉換材料。材料合計按六個材料格分欄，單價以整數金幣輸入。

點擊材料可複製拍賣搜尋名稱，省略簽名、星數及改造條件。組數無條件進位；飼料包含達到第九階的級別最後 46～50 等區間。

## 星塵

選擇期望值或目標累積成功率模式，設定主星塵及支援效果範圍。每次任務基礎獎勵為通用材料與指定級別材料各 2 個；加倍區塊可勾選皇家學院水晶、圖騰或藥水、活動。圖騰與藥水互斥。通用材料不足時，另計 E 級任務。

設定保存在同一瀏覽器的本機儲存空間；切换瀏覽器或裝置不會自動同步。
