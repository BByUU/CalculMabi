# 瑪奇小算盤 CalculMabi

繁體中文瑪奇玩家工具，提供技能修練與升段備料、聚能材料、星塵任務次數、特性升級需求、騎士團副技能修練時間計算與讀書型技能升級查詢。

[開啟網站](https://bbyuu.github.io/CalculMabi/)

## 功能

- **技能**：選擇技能與 Rank，調整修練加成、項目及配方，計算達到 30% 或 100% 修練值的操作次數與材料；升段頁依考場目標合計購物清單。
- **聚能**：按武器及級別規劃開放階段，每階獨立設定藥水與次數；支援材料查找、分格合計、轉換材料、飼料、組數及金額。
- **星塵**：主星塵固定升到 Rank 15、支援效果固定升到 Lv.10；目前等級可直接輸入或按左右按鈕增減，計算任務需求，可選期望值或目標累積成功率，套用任務獎勵加倍並補足通用材料缺額。
- **特性**：19 種特性附遊戲卡片圖示，目前等級可直接輸入或按左右按鈕增減，每列璞黎點下顯示未扣持有點數的週數，目標固定 Lv.10，旁列升滿所需璞黎點、AP、一般與高級璞黎結晶；可切換遊戲排序（與遊戲特性視窗相同，預設）或顏色排序（修行、挑戰、交感分組），選擇存在瀏覽器；顏色排序在各類下方顯示結晶、升級 AP 與週數小計，遊戲排序則集中於表格下方；依修行、挑戰、交感三種璞黎分開扣除目前持有點數，列出缺少點數及以每週 1,500 點上限估算的週數。
- **騎士團**：聖盾庇護與聖靈同步各 5 個副技能，名稱前附對應圖示，等級可直接輸入或按左右按鈕增減，另填修練值，依每級每次修練值列出練滿目前等級與升到 Lv.15 的次數及時間。聖盾庇護預設每 20 秒一次、庇佑步伐每 30 秒一次，可勾選「一次三人」：只有針對隊友的福音傳遞、恢復祈禱與復原祈禱各級所需次數除以 3 後向上取整（庇佑步伐維持單次），再加總升滿的施放次數與時間；預設不勾選，設定會保留。聖靈同步的復甦的靈魂每 60 秒、復活的權杖每 10 秒一次，啟迪之光、守護者的誓約只計次數；間隔都可調整。魔法反制不算次數，只列預估時間（練滿約 30 分鐘）。聖光顯靈依硫磺蜘蛛王房刷怪計算：Lv.n 每殺 n 隻算一次修練，預設每分鐘召喚 23.2 隻、每趟刷 50 分鐘後花 3 分鐘收怪施放（期間王不召喚），列出時間、隻數與趟數；三個數值可調整並保留。魔法反制、守護者的誓約與復活的權杖名稱旁提供「?」，點按或鍵盤操作可展開修練方式。

「讀書型技能」分頁列出音樂知識、作曲、休息、包紮、營火、魔法陣知識及冥想的簡易升級方式。七個技能欄位名稱前附對應圖示。每格上行列來源或對話對象，下行列書名、道具或任務需求；多步任務以箭頭濃縮流程，詳細材料與觸發條件保留在詳情。移到格子右側的「?」、鍵盤選取問號或手機點按問號可查看詳細書名、任務步驟及取得方式；格子文字不觸發詳情，上方兩種特別商店的問號集中說明領券任務；按 Esc 或點其他位置關閉。藍、紅、綠分別標示秘密商店、空寶箱任務及拉布的項鍊任務。尚無資料的階段留白。
